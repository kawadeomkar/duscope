# duscope-mcp

Stdio MCP server layer for [duscope](https://github.com/kawadeomkar/duscope), a disk-usage
analyzer for macOS and Linux.

This crate is an internal part of duscope, published to crates.io only because
the `duscope` crate depends on it. Its API makes no stability promise before
1.0 and may change in any release: the `duscope` binary is the only supported
entry point.
