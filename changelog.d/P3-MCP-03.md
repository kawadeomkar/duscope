### Added
- `duscope mcp --roots DIR` runs an MCP server on stdin and stdout for AI agents, speaking the 2026-07-28 protocol and the 2025-11-25 `initialize` handshake. A client reaches nothing outside `--roots`: a path holding `..`, a link that leads out, and an index file named for a scan are refused with `refused_path`, and a saved scan whose root lies outside the roots is not found. A tool's result is the envelope its verb prints with `--json`, byte for byte, with a one-line summary; `--max-chars` caps every result as it caps the verbs' output, and `--log-level` sets what reaches stderr.
