### Added
- `duscope mcp --allow-delete` offers `duscope_delete`, the tool that moves entries to the Trash and never deletes them permanently. Each item names a handle from `duscope_explain` and the bytes it should free (`expect_bytes`, within 1%); the tool is a dry run unless `dry_run` is false, its result is `clean`'s plan, and a path outside `--roots`, a handle that does not verify or has expired, a refused item, a size off by more than 1%, or an item whose size no saved scan knows stops the call; a call cancelled, past its deadline, or still to move anything when the client closes the server's input moves nothing, and one that has begun is answered with what it moved. Without the flag the tool is not listed and a call to it is an unknown tool. The tool is marked for confirmation on every call (`_meta["anthropic/requiresUserInteraction"]`), which is the client's to honour.
